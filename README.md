# EcoMarket-Marilud-Uribe-P

1. Descripción y Contexto del Proyecto
EcoMarket es una tienda en línea dedicada exclusivamente a productos ecológicos, reutilizables y sustentables. Su objetivo es ofrecer una plataforma accesible y atractiva donde los usuarios puedan explorar productos, conocer sus beneficios y realizar compras responsables.

¿Por qué es relevante este proyecto hoy?

Tendencia de Consumo Consciente: El consumidor moderno no solo busca productos, busca alineación con sus valores. El mercado de productos sostenibles está en auge, y las plataformas que no transmiten "frescura", "transparencia" y "ética" visualmente, pierden competitividad.
Desafío de UX/UI "Clean": Diseñar para sostenibilidad implica dominar el uso del espacio en blanco, paletas de colores naturales y tipografías legibles. Este proyecto entrena al desarrollador en la creación de interfaces que transmiten calma y confianza.
Complejidad Técnica sin Scripts: Al restringir el uso de JavaScript, el proyecto obliga a explotar al máximo las capacidades de CSS3 (Selectores avanzados, Grid, Flexbox, Pseudo-clases para interactividad), una habilidad fundamental para optimizar el rendimiento de carga.
